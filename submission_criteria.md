# Submission Criteria

Please follow the following IMPORTANT SUBMISSION GUIDELINES throughout the semester:

1. Compile all written work, math derivations, figures, and outcomes into ONE single PDF file.

2. If your solution requires code:

   - include your pseudo code in the submitted PDF.

   - Host your code on GitHub, Google Colab, or a shared institutional drive.

   - Embed the hyperlinked URL prominently. Ensure permissions are set so the instructor/TA can access or run the link.

   Alternatively, you may add the source code at the end of PDF file for submission.

3. Do NOT attach raw `.py`, `.ipynb`, `.cpp`, or `.zip` files to Blackboard. Non-PDF file attachments will receive a grade penalty or be returned ungraded.
